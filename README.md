IoT and GSM Based Multi-Disaster Detection and Alert System
Project Overview 
This system monitors environmental hazards using ESP thirty two, BME two eighty, ADXL three forty five, and MQ two sensors. It sends real-time data to Blynk and triggers emergency SMS and calls via SIM eight hundred L module during critical events.
Key Components
ESP thirty two Microcontroller
SIM eight hundred L GSM Module
BME two eighty Sensor
ADXL thirty four five Accelerometer
MQ two Gas Sensor & Flame Sensor
